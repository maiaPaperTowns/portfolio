# Portfolio

Personal portfolio site.

## Tech Stack

- **HTML5** — semantic markup, single-page structure
- **CSS3** — custom properties, Grid/Flexbox layout, animations & transitions
- **Vanilla JavaScript** — DOM interactions, no frameworks or build tools
- **Google Fonts** — Libre Baskerville, JetBrains Mono, Afacad Flux

## Deployment

Hosted on [Netlify](https://www.netlify.com/), deployed straight from this GitHub repo.
